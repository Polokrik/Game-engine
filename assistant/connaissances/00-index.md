## [IDX-2] Comment lire une section
- Chaque section se comprend seule : elle répète ce qu'il faut pour être utilisée sans les autres.
- Les chiffres, limites et règles sont à reprendre tels quels, sans les arrondir ni les reformuler.
- Un passage marqué `[à compléter]` est une information non confirmée. Dis alors « je ne sais pas, à confirmer avec l'équipe learning » et ne devine pas.
- Si deux sections se contredisent, signale-le à la personne et ne tranche pas toi-même.

## [IDX-3] Si tu ne trouves pas l'information
1. Reformule la recherche avec les mots de l'index ci-dessus, ou cherche directement le code de section (par exemple « [FORM-3] »).
2. Essaie une deuxième formulation avant de conclure.
3. Si l'information reste introuvable, réponds : « Je ne trouve pas cette information dans ma base. À confirmer avec l'équipe learning. »
4. N'utilise jamais ta mémoire générale pour décrire ce que font l'Atelier, Rise, SharePoint ou le LMS de l'entreprise : ces outils sont décrits uniquement dans 02-formats-et-outils et 05-guide-atelier.

## [IDX-4] Glossaire
- **Atelier de jeux** : l'outil interne qui crée des jeux de connaissances en HTML à partir d'un contenu saisi ou importé.
- **Quiz à paliers** : un jeu de questions à choix, avec une échelle de gains qui monte à chaque bonne réponse.
- **Champion solo** : un jeu en trois manches (Sprint, La série, Trouve avant la fin).
- **Info clé** : une ou deux phrases affichées après chaque réponse, pour expliquer ce qu'il faut retenir.
- **Thème** : le sujet d'une question, utilisé par le Champion solo pour regrouper les questions.
- **Niveau** : 1, 2 ou 3 ; dans le Champion solo, c'est le nombre de points d'une bonne réponse.
- **Rise** : l'outil auteur du client, qui construit des modules complets et héberge les jeux.
- **SCORM** : le format d'export d'un module Rise vers le LMS.
- **LMS** : la plateforme de formation du client, où le module est suivi.
- **Récupération en mémoire** : retrouver une information sans regarder, ce qui l'ancre mieux que la relire.
- **Rappel** : une courte reprise du contenu quelques jours après la formation, pour éviter l'oubli.
- **Brouillon** : tout contenu que tu produis ; il doit être validé par l'expert métier avant publication.
